@AGENTS.md

## Architecture
- Next.js 16 (App Router, Turbopack), React 19, Tailwind 4, shadcn/base-ui, GSAP + framer-motion, TypeScript strict. Read `node_modules/next/dist/docs/` first (see AGENTS.md).
- Pages in `src/app/(marketing)/` (home, about, blog, contact, dj-service/[location], inquire, podcast, privacy, the-team); components in `src/components/`; data, SEO, locations and blog helpers in `src/lib/`; copy in `content/*.md`.
- `src/proxy.ts` (Next 16 middleware) sets the visitor location cookie/header (brandon, winnipeg, regina) and rewrites `Accept: text/markdown` or `*.md` requests to `src/app/agent-md/`. Responses vary on Accept.
- `next-env.d.ts` and `tsconfig.tsbuildinfo` are gitignored. Route typings (`RouteContext`) are generated by `next build`/`next dev`, so run a build before `tsc` on a fresh clone.
- Deploy: Vercel (no `.vercel` link on a1; @vercel/analytics in use; `main` is the working branch). No required env vars in code beyond `NEXT_RUNTIME` (set by Next).
